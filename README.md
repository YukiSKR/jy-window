# 极域屏幕广播 · 窗口化工具

把极域电子教室学生端「屏幕广播」的全屏窗口，改成**带标题栏、能拖动、能最小化**的普通窗口，
  
并且在老师锁键盘时把**键盘控制权拿回来**。

- 版本：3.1（Mika 浅色二次元界面 + 键盘解锁）
- 文件：`JyWindow.exe`（单文件，双击即用，目标机不需要装 Python）
- 适用：极域课堂管理系统 V6.0（2016 豪华版）学生端 `StudentMain.exe`

---

## 一、快速开始

1. 双击 `JyWindow.exe`，UAC 弹窗选「是」（**必须**，原因见原理第 5 节）。
2. 点 **开始监控**（或者按空格）。
3. 老师开始屏幕广播 → 广播窗口会自己变成一个小窗口，右上角有 ✕ 和最小化。
4. 想收起来就点 **最小化**，或者直接点窗口的最小化按钮。
5. 键盘被锁住时，把左侧 **「键盘解锁」** 的开关拨开（或按 `K`），
     
   键盘立刻还给你，120 秒后自动恢复。

**界面**：以 mika 立绘为背景的浅色二次元布局，左侧是毛玻璃卡片（状态 / 按钮 / 日志），
  
右侧是看板娘 Mika，头顶有会打字冒字的对话框。按钮是粉白渐变的糖果胶囊，悬停会
  
轻轻上浮、按下会下沉；监控时状态圆环会转动呼吸；后台飘着花瓣和星光。

**互动（都可以试试）**：

| 动作                     | 会发生什么                     |
| ---------------------- | ------------------------- |
| 点看板娘（右半边任意位置）          | Mika 会说话，冒爱心，右下角「羁绊」+1 颗心 |
| 点画面空白处                 | 炸开一圈爱心 / 星星               |

| 鼠标划过按钮                 | 按钮上浮、变色、变描边               |
| `空格` / `W` / `M` / `R` | 开始停止 / 立即窗口化 / 最小化 / 还原全屏 |
| `K`                    | 键盘解锁开关（会冻结学生端进程）          |

| 按钮          | 作用                                                                |
| ----------- | ----------------------------------------------------------------- |

| 立即窗口化       | 对当前找到的广播窗口立刻执行一次（W）                                               |

| 结束学生端       | 直接结束 `StudentMain.exe`，键盘 100% 恢复（连 `BlockInput` 一起解），但老师那边可能显示离线 |

>

>   
> 万一工具被强杀，下次启动会自动把学生端叫醒（靠 `%TEMP%\jywindow_kb.lock` 记录）。

## 二、原理

### 1. 极域的「全屏」到底是什么

Windows 里一个窗口长什么样，由两组位标志决定：

- `GWL_STYLE`（基本样式）：有没有标题栏、边框、最小化按钮
- `GWL_EXSTYLE`（扩展样式）：是否置顶、是否在任务栏出现

极域的屏幕广播窗口是这么组合出来的：

```
WS_POPUP            无边框、无标题栏（看起来"没有窗口"）
+ 尺寸 = 整个屏幕     铺满
+ WS_EX_TOPMOST      永远压在所有窗口上面
+ 全局键盘钩子        吃掉 Win / Alt+Tab，让你切不出去
```

所谓"强制全屏"，本质就是**没有 `WS_CAPTION`（标题栏）+ 铺满屏幕 + 置顶**这三件事凑在一起。

### 2. 我们做的四步

```
①  style |= WS_CAPTION | WS_SYSMENU | WS_MINIMIZEBOX | WS_THICKFRAME
    → 长出标题栏、系统菜单、最小化按钮、可拖拽的边框

②  style &= ~WS_POPUP
    → 从"弹窗"变回"重叠窗口"，任务栏和 Alt+Tab 才认得它

③  exstyle &= ~WS_EX_TOPMOST ;  exstyle |= WS_EX_APPWINDOW
    → 取消强制置顶，并让它出现在任务栏

④  SetWindowPos(hwnd, HWND_NOTOPMOST, x, y, w, h,
                 SWP_FRAMECHANGED | SWP_SHOWWINDOW)
    → 关键一步。只改样式位系统不会重画边框，
       SWP_FRAMECHANGED 强制重新计算"非客户区"，新边框才真正出现；
       顺便把窗口缩小、居中、Z 序降到普通层
```

两个容易踩的坑，工具里都处理了：

- **最小化状态下改尺寸没用**：窗口最小化时 `SetWindowPos` 只改"还原后应该在的位置"，屏幕上毫无变化。必须先 `ShowWindow(SW_RESTORE)` 再改。
- **只改样式不重画**：不加 `SWP_FRAMECHANGED`，样式位改了但画面还是老样子。

### 3. 为什么每 0.5 秒复查一次（以及怎么避免和极域抢焦点）

窗口样式是**系统级属性，不属于应用私有**，改完就一直有效——直到极域自己再设一遍。
  
极域在重新广播、切分辨率、全屏重绘时可能再次 `SetWindowPos` 把自己拉回全屏，所以工具做成轮询：发现样式被改回去就再压一次。

但这一步必须非常克制，否则会出事（v1.0 就踩过这个坑）：

| 问题                                 | 后果                           | v2.0 的做法                                                                      |
| ---------------------------------- | ---------------------------- | ----------------------------------------------------------------------------- |
| `SetWindowPos` 没带 `SWP_NOACTIVATE` | 每改一次就把广播窗口提到前台，和极域互相抢，键鼠直接卡死 | **所有窗口操作强制带 `SWP_NOACTIVATE`**，只改样式和位置，绝不抢焦点                                  |
| 每 0.4 秒无脑重试                        | 极域每帧拉回全屏 → 日志刷屏、画面闪、CPU 飙    | 两次操作至少间隔 **1.5 秒**；相同日志 3 秒内不重复打印                                             |
| 死不认输地对抗                            | 越改越乱，用户完全没法操作                | 10 秒内被抢回 3 次就判定“极域锁死了全屏”，**彻底停止自动尝试**（不会再周期性闪屏），状态显示「无法接管」；只有手动点「立即窗口化」才会再试一次 |

也就是说：正常情况下它只在投屏开始时动手一次；如果极域死守全屏，它会主动退让，
  
把控制权还给你，而不是跟你抢电脑。

### 3.5 键盘锁是怎么做的，我们怎么解

> 完整版（含流程图、操作步骤、常见问题）见 **`键盘解锁说明.md`**，这里只列结论。

极域锁键盘不是"拦住某个窗口的按键"，它有两条独立的线：

| 手段                                          | 原理                                                                    | 我们的解法                                                                                                         |
| ------------------------------------------- | --------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| 全局低级键盘钩子 `SetWindowsHookEx(WH_KEYBOARD_LL)` | 装在 `StudentMain.exe` 的线程里，每个按键先送进它的回调，`Win`/`Alt+Tab`/`Alt+F4` 在那里被吞掉 | 把 `StudentMain.exe` **挂起**（`NtSuspendProcess`），它的回调就永远返回不了；系统等不到回调（`LowLevelHooksTimeout`）就直接把按键交给下一个环节——键盘活了 |
| `BlockInput(TRUE)`                          | 系统级屏蔽物理输入，只有调用的那个线程能解、或按 `Ctrl+Alt+Del` 打断                            | 挂起解不了它，只能**结束进程**（`BlockInput` 随进程一起消失）。所以额外做了「结束学生端」按钮                                                       |

挂起用的是 `OpenProcess(PROCESS_SUSPEND_RESUME)` + `ntdll.NtSuspendProcess/NtResumeProcess`：

```
冻结：NtSuspendProcess(h)   → 该进程所有线程挂起
恢复：NtResumeProcess(h)    → 线程恢复，学生端继续工作（不用重启、不掉线）
```

这套做法**不注入 DLL、不装驱动、不改极域文件**，和窗口化的思路一致：只借用
  
Windows 自己的调度和超时机制。代价是冻结期间学生端是死的（投屏停帧），
  
所以做了三个保险：

1. 开关自带 120 秒倒计时，到点自动恢复；
2. 关掉工具（`WM_CLOSE`）时会先恢复再退出；
3. 启动时读 `%TEMP%\jywindow_kb.lock`，如果上次是被强杀的，自动把记录里的进程叫醒。

### 4. 怎么找到"那个"窗口

```
EnumWindows           遍历所有顶层窗口
  → GetWindowThreadProcessId  只要 StudentMain.exe 的
  → GetWindowRect             面积 ≥ 屏幕 85% 的
  → 或类名含 broadcast / elc / deskmon 等关键词的
```

识别到之后才动手，不会误伤资源管理器、输入法等系统窗口。

### 5. 为什么必须管理员

极域学生端跟随系统服务以**高完整性级别**运行。Windows 有 UIPI（用户界面特权隔离）机制：低权限进程不能操作高权限进程的窗口，`SetWindowLongPtr` 会直接返回 `ERROR_ACCESS_DENIED (5)`。

所以 exe 启动时用 `ShellExecuteW(..., "runas", ...)` 自己重新拉起来，弹一次 UAC。

### 6. 和 JiYuTrainer 那类工具的区别

|               | 本工具               | 注入类工具（JiYuTrainer 等）            |
| ------------- | ----------------- | ------------------------------- |
| 手段            | 外部调用 Win32 窗口 API | 往 StudentMain.exe 里注入 DLL、装内核驱动 |
| 是否碰进程内存       | 否                 | 是                               |
| 杀软误报          | 概率低               | 很高                              |
| 能否绕过键盘钩子      | **不能**            | 能                               |
| 能否解锁 USB / 网络 | 不能                | 能                               |
| 极域文件改动        | 零                 | 会改                              |

本工具是"最小干预"：只动窗口的显示属性，其他一概不碰。

## 三、限制（务必看）

1. **窗口化本身解不了键盘锁**，要用上面说的「键盘解锁」开关；另外教师如果开了
     
   「锁定键盘鼠标」，挂起也可能不管用（`BlockInput` 那条线），这时只能「结束学生端」。
2. **画面不会等比缩放。** 广播流按 1600×900 编码，窗口小于屏幕时右下角被裁掉，不是缩小。想完整看清就把比例设成 **100%**（只加标题栏）。
3. **教师端可以强制拉回全屏。** 远程设置里勾了「以全屏接收广播」时，你改完它可能被推回去。
4. **教师端能看到你的屏幕。** 变成小窗再开别的程序，一眼就能看见。
5. 部分杀毒软件可能对"改窗口样式"的小众程序敏感，若被拦截请自行判断是否放行。
6. 课堂软件通常有校规约束，用不用、什么时候用，自己判断后果。

> 补充：极域学生端本身在广播画面上**点右键**就有「窗口显示模式」（缩放显示 / 全屏幕显示 / 最顶层显示）。如果老师没禁用这个菜单，优先用它——那是官方行为，比本工具干净。

## 四、没有广播时怎么自测

```bash
# 1. 起一个假的广播窗口（全屏 + 置顶 + 无边框 + 类名 TESTBCASTWND）
python src\tools\fake_broadcast.py

# 2. 让工具去处理它（加 --process 指定监控 python.exe，--no-elevate 免提权）
JyWindow.exe --process python.exe --no-elevate --watch
```

正常结果：假窗口从 1600×900 全屏变成带标题栏的 85% 窗口，并且不再是置顶。

## 五、源码与重新打包

```
极域窗口化工具\
├─ JyWindow.exe        成品（单文件，含素材）
├─ src\jywin_gui.py         源码（Canvas 自绘界面 + ctypes 调 Win32）
├─ src\mika_src.jpg         原始立绘（要换背景图就换它）
├─ src\make_assets.py       从立绘生成背景 / 圆头像 / 图标
├─ src\tools\fake_broadcast.py  自测用的假广播窗口
├─ assets\bg.jpg            界面背景（脚本生成，可直接替换）
├─ assets\mika_face.png     左上角圆形头像
├─ assets\icon.ico / icon.png  程序图标（exe 与窗口都用它）
├─ build.bat                一键重新打包
├─ 使用说明.md               本文件
└─ 键盘解锁说明.md           键盘控制原理与操作（详细版）
```

重新打包（需要 Python 3.8+ 且带 tkinter，另需 Pillow）：

```bat
build.bat
```

等价命令：

```bat
python -m pip install --upgrade pyinstaller pillow
python -m PyInstaller --noconfirm --onefile --noconsole --name JyWindow ^
    --icon assets\icon.ico --add-data "assets;assets" ^
    --distpath . --workpath build --specpath . src\jywin_gui.py
```

> 注意：素材是靠 `--add-data "assets;assets"` 打进 exe 的，漏了这条命令打出来的
>   
> 程序会没有背景图（只剩纯色界面）。

命令行参数（可选）：

| 参数                  | 说明                             |
| ------------------- | ------------------------------ |
| `--watch`           | 启动后立即开始监控                      |
| `--process xxx.exe` | 额外监控的进程名（默认只盯 studentmain.exe） |
| `--no-elevate`      | 不自动请求管理员权限（调试/自测用）             |

## 六、用到的 Win32 接口

| 接口                                                        | 用途                                   |
| --------------------------------------------------------- | ------------------------------------ |
| `EnumWindows`                                             | 遍历顶层窗口                               |
| `GetWindowThreadProcessId` / `QueryFullProcessImageNameW` | 判断窗口属于哪个进程                           |
| `GetWindowRect`                                           | 取窗口尺寸，判断是否铺满屏幕                       |
| `GetWindowLongPtrW` / `SetWindowLongPtrW`                 | 读写 `GWL_STYLE`、`GWL_EXSTYLE`         |
| `SetWindowPos`                                            | 改位置/尺寸/Z 序，`SWP_FRAMECHANGED` 触发边框重算 |
| `ShowWindow(SW_RESTORE / SW_MINIMIZE)`                    | 还原 / 最小化                             |
| `IsIconic`                                                | 判断是否处于最小化                            |
| `ShellExecuteW("runas")`                                  | 自提权                                  |
